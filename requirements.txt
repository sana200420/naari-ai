# torch is deliberately NOT pinned here.
#
# The Hugging Face Space (Gradio SDK on zero-a10g) ships its own torch build
# that the `spaces` package expects to patch; pinning a CPU wheel over it
# risks breaking that. Railway's CPU-only torch pin therefore lives in the
# Dockerfile instead -- see the comment there. The thing to avoid on any
# *non-HF* host is a plain `pip install torch`, which resolves the default
# CUDA wheel and drags in ~3GB of nvidia-* libraries a CPU host can never
# execute. That bloat is why builds failed from 2026-09-01 (892aaa1) onward,
# leaving production stuck on the Phase 0 mock.
